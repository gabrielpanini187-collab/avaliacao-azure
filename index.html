Questão 3 - Como configurar e conectar em uma máquina virtual na Azure

Para configurar e conectar em uma máquina virtual na Microsoft Azure, uma pessoa que nunca utilizou a plataforma pode seguir os seguintes passos:

1. Acessar o portal da Azure

Primeiramente, deve-se acessar o portal da Microsoft Azure pelo navegador e entrar com uma conta Microsoft que tenha acesso à Azure.

2. Criar uma máquina virtual

No portal da Azure, deve-se procurar pela opção "Máquinas Virtuais" e selecionar a opção para criar uma nova máquina virtual.

3. Configurar as informações básicas

Durante a criação, é necessário informar alguns dados, como:

  • Assinatura utilizada;
  • Grupo de recursos;
  • Nome da máquina virtual;
  • Região onde a máquina será criada;
  • Imagem do sistema operacional;
  • Tamanho da máquina virtual.

4. Configurar o usuário e a senha

Também é necessário criar as credenciais que serão utilizadas para acessar a máquina virtual. No caso de uma máquina Windows, pode ser configurado um nome de usuário e uma senha. No caso de Linux, normalmente pode ser utilizado um usuário e uma chave SSH.

5. Configurar as regras de rede

A Azure permite configurar as portas de rede que poderão receber conexões. Para uma máquina Windows, normalmente é necessário permitir a porta RDP (3389). Para uma máquina Linux, normalmente é utilizada a porta SSH (22).

6. Criar a máquina virtual

Depois de revisar as configurações, deve-se selecionar "Revisar + criar". Após a validação das configurações, deve-se clicar em "Criar". A Azure então começará a criar os recursos necessários para a máquina virtual.

7. Aguardar a implantação

É necessário aguardar até que a implantação seja concluída. Quando a máquina virtual estiver pronta, ela aparecerá no portal da Azure como uma máquina virtual disponível.

8. Localizar o endereço IP

Ao abrir a página da máquina virtual criada, é possível encontrar o endereço IP público. Esse endereço será utilizado para realizar a conexão com a máquina.

9. Conectar em uma máquina Windows

Se a máquina virtual criada utilizar Windows, pode-se utilizar o protocolo RDP (Remote Desktop Protocol). No computador local, pode-se abrir o aplicativo "Conexão de Área de Trabalho Remota", informar o endereço IP público da máquina virtual e realizar a conexão utilizando o usuário e a senha configurados anteriormente.

10. Conectar em uma máquina Linux

Se a máquina virtual utilizar Linux, normalmente a conexão é realizada utilizando SSH. No Windows, por exemplo, pode-se utilizar o PowerShell ou outro programa compatível com SSH.

O comando terá uma estrutura semelhante a:

ssh usuario@IP_DA_MAQUINA

11. Acessar a máquina virtual

Após a autenticação ser realizada com sucesso, o usuário estará conectado à máquina virtual e poderá utilizá-la como se estivesse trabalhando diretamente nela.

12. Encerrar a máquina quando não estiver utilizando

Depois de terminar os testes ou atividades, é importante verificar a máquina virtual no portal da Azure e, quando apropriado, interrompê-la ou excluí-la. Isso evita que recursos continuem sendo utilizados desnecessariamente e ajuda a controlar os custos da conta.
